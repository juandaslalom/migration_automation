# Migration Automation

A Streamlit application for managing migration automation processes.

## Installation

1. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Running the Application

To run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your default browser at `http://localhost:8501`.

## Features

- Multi-tab interface for different setup steps
- Input fields for site name, release name, and migration folder configuration
- File upload functionality for Excel and equipment files
- Clean, user-friendly interface

## Usage

1. Navigate through the tabs to complete each setup step
2. Fill in the required information (site name, release name, migration folder)
3. Upload your Excel and equipments files
4. Follow the instructions to provide strategy validation evidence
